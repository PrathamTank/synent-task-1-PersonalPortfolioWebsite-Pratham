# Personal Portfolio Website | Pratham Tank

A sleek, modern, and fully responsive personal portfolio website built from scratch using clean semantic markup, custom CSS variables, and native client-side JavaScript. This website highlights my focus areas, technical skill set, creative portfolio, and includes an interactive contact form.

🔗 **Live Link**: [portfolio-pratham-tank.vercel.app](https://portfolio-pratham-tank.vercel.app/)

---

## 🚀 Key Features

* **Responsive Design**: Mobile-first grid layouts supporting desktops, tablets, and mobile devices seamlessly.
* **Sticky Navigation**: Smooth-scrolling anchor links with real-time active link highlighting as the page scrolls.
* **Hamburger Mobile Menu**: Dynamic slide-out navigation drawer for mobile and tablet viewports.
* **Skills Tagging System**: Custom interactive categories with micro-interaction hover transitions.
* **Project Cards Grid**: Showcases major projects (Landing Page, AI Chatbot, Portfolio) with hover-animated icons and live deployment links.
* **Client-Side Form Validation**: Fully styled form inputs with prompt error alerts and instant resets.

---

## 🛠️ Technology Stack

* **Structure**: HTML5 (Semantic elements like `<header>`, `<nav>`, `<section>`, `<footer`, `<svg>`)
* **Styling**: CSS3 (Vanilla design tokens, CSS variables, custom grid systems, and flex layout models)
* **Scripts**: Vanilla ES6 JavaScript (DOM manipulation, scroll offset listeners, and event callbacks)
* **Aesthetics & Typography**: Google Fonts (`Poppins` font-family) and inline SVG vectors.

## 💻 Getting Started Locally

Since the project is built with static technologies, you do not need to install complex dependencies.

### Option 1: Direct Execution
Simply open the `index.html` file in any modern web browser:
```bash
# On Windows PowerShell
Start-Process "index.html"
```

### Option 2: Local Server (Recommended)
To run the project with automatic hot-reloading:
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Click the **Go Live** button in the status bar at the bottom right.

## 📱 Responsive Layout Details

The site scales dynamically across these viewport thresholds:
* **Desktop (`> 992px`)**: Classic side-by-side flex alignments with double-column grids.
* **Tablet (`<= 992px`)**: Wraps multi-column modules into simple vertical card sequences.
* **Mobile Menu (`<= 768px`)**: Collapses header links into a slide-out hamburger navigation layout.
* **Small Screens (`<= 480px`)**: Fits buttons to full-width targets and scales typography for enhanced readability.
